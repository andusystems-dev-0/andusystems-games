# ansible/ — k3s install + post-boot

Installs 3-node HA k3s on the Terraform-provisioned VMs, then MetalLB + its pool. Everything
app-level is ArgoCD, not Ansible. Run by `deploy.yml`/`redeploy.yml` after `terraform apply`.

```
ansible.cfg                     # host-key tolerance (VMs get new keys on redeploy)
k3s.yml                         # HA k3s (cluster-init + joins) → MetalLB + games pool
inventory/games/hosts.yml       # generated by `terraform apply` (git-ignored)
inventory/games/hosts.yml.example  # shape reference / --syntax-check
```

- k3s HA: first node `--cluster-init`, others join; Traefik ships with k3s; `--disable servicelb`
  (MetalLB owns LB IPs).
- MetalLB pool `10.238.70.50-.69`; Traefik VIP `10.238.70.50` (the Pangolin resources + Cloudflare
  Tunnel target this).
- Validated: `ansible-playbook -i inventory/games/hosts.yml.example k3s.yml --syntax-check`.
